# 🎙️ Speech to Text Converter

A Speech-to-Text web application built with Python, Streamlit, and OpenAI Whisper.

## 🚀 Live Demo

🎙️ **Try the application here:**

https://daniyatr-speech-to-text-convertor-app-dzpryi.streamlit.app/

## ✨ Features

- Upload audio or video files
- Supports MP3, WAV, M4A, MP4, MPEG, MPGA and WEBM
- Converts speech into text
- Built using OpenAI Whisper
- Simple and user-friendly Streamlit interface

## 🛠️ Technologies Used

- Python
- Streamlit
- OpenAI Whisper
- PyTorch
- FFmpeg
